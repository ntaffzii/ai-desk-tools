# Notice And Attribution

`ai-desk-tools` is original local MCP server work for personal AI-agent tooling. It studies common MCP server and agent-tool patterns, but it is not an official fork, distribution, or endorsement of any upstream project.

## Inspiration

Design and organization were informed by public MCP and agent-tool projects such as:

- `modelcontextprotocol/servers` - reference-style MCP server organization.
- `mark3labs/mcp-filesystem-server` - allowed-directory visibility and filesystem safety patterns.
- `googleapis/mcp-toolbox` - toolbox-style discoverability and registry thinking.
- `lastmile-ai/mcp-agent` - workflow-aware agent design.
- `tadata-org/fastapi_mcp` - schema-driven tool exposure.
- `TensorBlock/awesome-mcp-servers` and `abordage/awesome-mcp` - MCP server catalogs and ecosystem discovery.

## Companion Repo

This tools repo is designed to pair with:

[ntaffzii/Skill-Agents](https://github.com/ntaffzii/Skill-Agents)

`Skill-Agents` contains the skills, workflows, examples, local LLM settings, and provider configuration docs.
